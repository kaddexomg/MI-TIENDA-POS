Acceso Directo de Escritorio Windows 7 (Modo Ventana Nativa)

Configuración para ejecutar Chrome en modo quiosco/app sin consumo excesivo de RAM

Para que el cajero lo use como un sistema de facturación de escritorio a pantalla completa (sin barras de navegador ni distracciones):

  1. Haz clic derecho en el Escritorio de Windows 7 → Nuevo → Acceso directo.
  2. En la ruta del elemento, escribe:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --app="http://localhost:3080/pos.html"
  3. Nómbralo MI TIENDA POS (Caja de Cobranzas) y dale Guardar.
  4. ¡Listo! Al darle doble clic, se abre al instante en 1 segundo con consumo mínimo de memoria RAM.
